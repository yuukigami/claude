Important Disclaimers

What this tool IS: A structured heuristic to narrow the methodology space and educate on tradeoffs.

What this tool IS NOT:

  • Not a substitute for statistical expertise (complex scenarios need expert design)
  • Not legal/medical advice (regulatory contexts have specific requirements)
  • Not a guarantee of validity (correct methodology ≠ correct implementation)
  • Not comprehensive (omits advanced niche methods)

Key Assumptions: I.I.D. by default, single primary metric, steady-state traffic, honest inputs, no novelty effects, U.S./tech context (alpha=0.05, power=0.80).

Glossary

MDE (Minimum Detectable Effect)
The smallest effect size you want to reliably detect. Smaller MDEs require exponentially more traffic.
Type I Error (False Positive)
Concluding a variant is better when it's not. Controlled by alpha (typically 0.05 = 5% false positive rate).
Type II Error (False Negative)
Failing to detect a real effect. Controlled by power (1-beta; typically 0.80 = 80% chance to detect real effect).
CUPED / CUPAC
Variance reduction techniques using pre-period covariates. Can reduce required sample size by 20-50%.
Sequential Testing
Methods that allow repeated looks at data without inflating false positive rate (e.g., alpha-spending, always-valid p-values).
FDR (False Discovery Rate)
When running many tests, the expected proportion of false positives among all significant results. Benjamini-Hochberg controls this.
Interference
When one user's treatment affects another user's outcome (e.g., network effects, marketplace dynamics). Violates independence assumption.
SRM (Sample Ratio Mismatch)
When observed traffic split differs from expected (e.g., 48/52 instead of 50/50). Indicates implementation bug or bias.
